 🌿 LifeFlow — AI Daily Planner & Productivity Suite

> **An AI-powered productivity workspace built with React, TypeScript, Node.js, Express, Tailwind CSS, and Google Gemini AI.**

LifeFlow is a modern all-in-one productivity application designed to help users efficiently organize their daily schedules, manage tasks, build habits, achieve goals, and improve focus using intelligent AI assistance. It combines clean design with powerful productivity tools to create a seamless planning experience.

---

## ✨ Features

### 👤 User Authentication
- Secure Sign Up & Login
- Personalized user profiles
- Session management
- Dynamic welcome greetings

### 📅 Daily & Monthly Planner
- Daily time-block planning
- Monthly calendar overview
- Focus block scheduling
- Milestone tracking

### ✅ Task Management
- Create, edit, and delete tasks
- Priority Levels (P1, P2, P3)
- Due dates
- Categories & Tags
- Task completion tracking
- Progress indicators

### 🔥 Habit Tracker
- Daily habit tracking
- Habit streaks
- Interactive habit calendar
- Completion statistics

### 🎯 Goal Management
- Create long-term goals
- Milestone tracking
- Progress visualization
- Target completion dates

### ⏱️ Pomodoro Focus Timer
- 25-minute focus sessions
- Short & long breaks
- Ambient focus sounds
- Productivity tracking

### 📊 Productivity Analytics
- Weekly productivity reports
- Task completion charts

- Interactive Chart.js dashboards

### 🏆 Achievements & Rewards
- Productivity badges
- Habit streak rewards

Powered by **Google Gemini AI**

- AI-generated daily schedules
